# Unity Gateway × Coding Agents ワークショップ

Unity Gateway経由でClaude Codeを使い、モデル選択、Smart Routing、予算、ポリシー、利用状況の分析を体験します。対応するGLM・KimiなどのOSS系モデルも、Claude CodeやCodexから利用できる仕組みを紹介します。

**推奨のブラウザコースは、参加者のPCへのツール導入が不要です。** ローカルコースも選べます。このワークショップ単独で受講でき、[AI Governanceワークショップ](../databricks-llmops-ai-governance-workshop/)のモデルサービスも任意で再利用できます。

## ワークショップ資料

| Notebook | 内容 |
|---|---|
| [ハンズオン](./Unity_Gateway_ハンズオン.py) | 参加者向けの操作手順と演習 |
| [事前準備ガイド](./事前準備ガイド.py) | 開催前の環境・権限・機能設定、導入、トラブル対応、設定の復元 |

## 進め方

1. 開催前に、講師・管理者が**事前準備ガイド**に沿って環境と権限を準備します。
2. 上記2つのPythonファイルを、ファイル名を変えずに同じWorkspaceフォルダへNotebookとしてインポートします。
3. **ハンズオンのセクション0**から進めます。

目安は**85分**、質疑を含めて90分枠を想定しています。章別の時間配分と発展演習は本編を参照してください。
