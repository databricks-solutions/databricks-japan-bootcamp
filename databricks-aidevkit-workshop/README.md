# Databricks AI Dev Kit Workshop

Databricks AI Dev Kit をローカル IDE（Claude Code / Cursor）向けに導入し、MCP 経由でワークスペースと連携するためのワークショップ用フォルダです。

## セットアップ手順

ローカル環境での AI Dev Kit のインストール、MCP 設定、動作確認、トラブルシューティングは次のドキュメントにまとめています。

- [Databricks AI Dev Kit インストールガイド（setup.md）](setup.md)
  - Databricks ワークスペース内のブラウザだけでは外部インストール手順にアクセスできない場合は、同じフォルダの `setup.md` を参照してください。
