# 応用編ハンズオンのサンプルデータ
こちらはAI/BIハンズオンセッションの後半（応用編ハンズオン）のサンプル用データです。
製造業向けのシナリオと、バックオフィス向けのシナリオから好きなものを選択してください。

## 製造業向けシナリオ
製品の売上・原価内訳 (材料/製造/物流)・粗利データを利用して、製品原価・粗利分析を行うシナリオです。
データはmanusumart/product_pnl.csvにあります。

## バックオフィス向けのシナリオ
研修受講履歴研修（従業員属性・評価集計 (最新評価・累計昇進) などを含む）のデータを利用して、研修ROI分析を行うシナリオです。
データはtechbridge/training_activities.csvにあります。
