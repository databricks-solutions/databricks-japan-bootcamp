# bootcamp-Genie-Agent
Genie Agentを使用したローコードでのエージェント開発

家電メーカー「ブリックス電機」（架空）の品質保証部を想定し、修理受付のデータ（テーブル）と社内文書（PDF・PPTX）を横断して分析する Genie Agent を、コードを書かずに作るハンズオンです。

## フォルダの構成

| パス | 内容 |
|---|---|
| `00_セットアップ` | スキーマと Volume を作り、`csv/` と `unstructured_data/` を Volume にコピーして、テーブルを作るノートブック（カタログとスキーマはウィジェットで指定） |
| `01_Genie Agent の作成（API）` | Genie Agent を API（`POST /api/2.0/genie/spaces`）で作るノートブック。テーブル・Volume・指示・サンプルの質問・ベンチマークをまとめて設定し、`[Volumeあり]` と `[Volumeなし]` の2つを作る |
| `02_シナリオと想定QA` | シナリオ、Genie Agent の作り方（画面で作る手順）、Agent モードで投げる質問と想定回答・検証ポイント |
| `csv/` | テーブルの元データ（products / production_lots / sales_monthly / repair_requests） |
| `unstructured_data/` | Genie Agent に追加する文書（取扱説明書10、品質会議の資料18、サービス技術情報5、保証規定・修理料金表1） |

## 進め方

1. ワークスペース管理者が［プレビュー］で「Genie エージェントによるボリューム内のファイル分析」を有効にする
2. このリポジトリを Git フォルダとして取り込み、`00_セットアップ` をサーバーレスで実行する
3. `01_Genie Agent の作成（API）` を実行して、Genie Agent を2つ作る（画面で作る場合は `02_シナリオと想定QA` の 4-1〜4-4）
4. `02_シナリオと想定QA` の手順に沿って、Agent モードで質問し、Volume あり／なしの答えを比べる

データはすべて架空です（対応メモの氏名・電話番号・住所もダミー）。
