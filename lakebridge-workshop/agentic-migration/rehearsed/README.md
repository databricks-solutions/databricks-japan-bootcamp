## 当日の使い方

通常は参加者が自分で変換する。変換の待ち時間が長い場合は、この実出力をSQL editorへコピーして実行し、差分レビュー・期待結果の比較へ進む。変換開始から成功表示を確認するまで、各ファイル約2〜3分だった。ブラウザ操作の切り替え・自動操作のトラブル対応時間は含まないため、30分の授業全体の実測ではない。

確認環境は講師権限のServerless SQL Warehouse。参加者権限での利用可否と同時実行時の待ち時間は未確認。会話からの単独 `/migrate` は自動操作でプロンプトが分割送信され内部エラーとなったため、独立した正常試行としては未検証。標準のMigration Project経由を使用する。

変換の成功表示は業務結果一致の証明ではない。生成されたコメント・説明も含め、実行と結果比較で確認する。
