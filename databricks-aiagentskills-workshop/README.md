# Databricks Agent Skills Workshop

Databricks Agent Skills をローカル IDE（Claude Code / Cursor）向けに導入し、Databricks ワークスペースと連携するためのワークショップ用フォルダです。

## セットアップ手順

ローカル環境での Agent Skills のインストール、旧 ai-dev-kit のアンインストール、動作確認、トラブルシューティングは次のドキュメントにまとめています。

- [Databricks Agent Skills セットアップガイド（setup.md）](setup.md)
  - Databricks ワークスペース内のブラウザだけでは外部インストール手順にアクセスできない場合は、同じフォルダの `setup.md` を参照してください。
